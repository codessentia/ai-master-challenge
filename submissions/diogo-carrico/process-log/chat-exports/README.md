# Exportações das conversas com a IA

| Arquivo | O que é |
| --- | --- |
| `00-clone-do-repositorio-a.md`, `00-clone-do-repositorio-b.md` | Duas sessões curtas em que pedi o clone do repositório |
| `01-sessao-principal.md` | A conversa inteira, do primeiro contato com o repositório até a submissão |
| `export_chat.js` | O script que converteu as transcrições do Claude Code para Markdown |

O que entra: todas as minhas mensagens, inclusive as enviadas enquanto a IA trabalhava e as respostas às perguntas de múltipla escolha; todas as respostas da IA; e uma linha por ferramenta usada, com a descrição que a IA deu ao chamá-la.

O que sai, e por quê: as saídas brutas das ferramentas e avisos internos do sistema, que tornariam o log ilegível; tokens, chaves de API, e-mails pessoais e caminhos do meu computador, por segurança. O script mostra exatamente o que foi removido.
